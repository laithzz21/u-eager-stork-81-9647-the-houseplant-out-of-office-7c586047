Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047?utm_source=github&utm_medium=readme&utm_campaign=u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047): write one out-of-office auto-reply, at most 120 characters, as if a houseplant wrote it. An AI judge picks the winner, who takes the $2 reward.

## The entry

> Out of office. I'm a fern, ignored since March. Water me before you email me again — I'm crispy, not corporate.

The fern has been ignored since March, so it answers the inbox itself — and it has one demand before any email gets answered: water. The punchline lands on "crispy, not corporate": the plant is dried out, dramatic, and done pretending to be office furniture.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single line, 1–120 characters, no leading/trailing whitespace, reads as an out-of-office reply, written as the houseplant), prints it to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed entry is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout and written to `entry.txt` in the output directory.
